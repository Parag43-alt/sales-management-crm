# 🚀 Hosho CRM - Enterprise Edition

> A modern, lightweight, and highly interactive Customer Relationship Management (CRM) dashboard built for high-performance sales teams. 

Hosho CRM bridges the gap between operational sales data and executive-level analytics, ensuring real-time decision-making without the bloat of traditional CRM systems.

## ✨ Key Features

* **📊 Executive Analytics Dashboard:** Real-time KPI tracking, Win/Close rates, and revenue forecasting using **Chart.js**.
* **💼 Pipeline Management:** Seamlessly update deal stages (Discovery ➔ Proposal ➔ Negotiation ➔ Closed Won).
* **🎉 Interactive UI/UX:** Premium dark-mode interface with micro-interactions, including success sounds and **Canvas Confetti** celebrations for closed deals.
* **🔒 Secure Data Persistence:** Built-in local storage engine for seamless data retention without requiring immediate backend sync.
* **⚡ Zero-Build Frontend:** Pure HTML, CSS, and Vanilla JavaScript. No heavy Webpack or `node_modules` required.
* **🛡️ Premium Alerts:** Integrated **SweetAlert2** for safe and modern CRUD operation confirmations.

---

## 🛠️ Tech Stack

**Frontend Architecture:**
* HTML5 / CSS3 (Custom Dark Enterprise Theme)
* Vanilla JavaScript (ES6+)
* [Chart.js](https://www.chartjs.org/) (Data Visualization)
* [SweetAlert2](https://sweetalert2.github.io/) (Interactive Popups)
* [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) (UI Animations)

**Backend Architecture (Optional/API Ready):**
* Python 3.x
* FastAPI (RESTful APIs)
* SQLite / MySQL
